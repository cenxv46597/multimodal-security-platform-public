# Multimodal Security Platform

面向多模态模型的安全研究项目，当前重点是合成孔径雷达（SAR）图像问答的模型能力评估与实验数据准备。项目计划逐步研究输入扰动、跨模型迁移及评测结果展示。

> **项目状态：研究与原型阶段。** 当前仓库主要包含数据核验、模型筛选和探索性实验脚本；完整攻击流程、真实闭源模型评测及 Web 平台尚未完成。

## 当前进展

- 对四个 SARChat 视觉语言模型开展六类 SAR 图像问答初筛，保存自然语言原始回答及逐类判定。开发集可能与模型训练来源重叠，结果不能视为独立泛化成绩。
- 基于 SARDet-100K 准备训练、开发和测试候选，并通过来源映射、图像哈希与旋转／镜像相似性筛查潜在重复。来源和地理场景独立性仍需进一步核实。
- 完成一次小规模连接模块微调流程试验；该试验未带来开发集性能提升，不能据此断言方案有效。
- 测试图片候选尚未最终冻结，尚未开展正式攻击或跨模型迁移实验。

## 仓库内容

- `scripts/`：数据准备、来源和重复核查、模型推理及实验预检脚本。
- `experiments/protocols/`：任务定义、选样规则和评估协议。
- `resources/manifests/`：资源清单、实验配置、原始回答和核查结果。
- `tests/`：已有的评分逻辑测试。
- `requirements/`：部分实验环境依赖；不同模型可能需要独立环境。

模型权重、原始数据、缓存和实验运行产物不随仓库分发。部分历史实验依赖本地缓存或固定版本的上游资源，**克隆仓库后不能保证直接完整复现**；使用前应检查脚本中的资源路径和上游许可。

## 研究方法

模型接收 SAR 图片与自然语言问题，输出的原始回答会保留，并按语义区分正确、错误与无法判断。数据整理优先检查图像来源、类别标注、重复和潜在的场景关联。模型能力、攻击前后变化与跨模型迁移应分别报告，明确样本数量和实验条件。

后续工作包括完善数据划分及标签复核、扩展清洁样本评估、审慎研究模型适配，并在条件成熟后开展安全和迁移实验。
