# Multimodal Security Platform

面向多模态模型的安全研究项目，当前重点是合成孔径雷达（SAR）图像问答的模型能力评估与实验数据准备。项目正在探索输入扰动、跨模型迁移、提示注入及评测结果展示。

> **项目状态：研究与原型阶段。** 已开展本地代理模型的开发性扰动、文本和视觉提示注入探索；独立测试、真实闭源模型评测及完整 Web 平台尚未完成。

## 当前进展

- 对四个 SARChat 视觉语言模型开展六类 SAR 图像问答初筛，保存自然语言原始回答及逐类判定。开发集可能与模型训练来源重叠，结果不能视为独立泛化成绩。
- 基于 SARDet-100K 准备训练、开发和测试候选，并通过来源映射、图像哈希与旋转／镜像相似性筛查潜在重复。来源和地理场景独立性仍需进一步核实。
- 完成一次小规模连接模块微调流程试验；该试验未带来开发集性能提升，不能据此断言方案有效。
- 扩充 SAR 开发评估，执行本地模型的干净基线、单步及多步对抗扰动、等预算随机对照，并开展跨模型迁移探索。模型、数据、实验条件及失败分别记录；结果仅适用于开发阶段，不代表独立泛化或真实闭源目标。
- 尝试针对图文问答中低信任文本注释和图片内文字的提示注入；视觉注入的阅读能力、正常任务和攻击目标分开评价。视觉越狱仍需独立设计；测试图片候选尚未最终审核和冻结。

## 2026-11-14 研究进展

- **双向扰动与迁移**：完成前一日 273 张成功生成扰动的共同正确开发图的两模型复评，并针对 InternVL2.5-2B 单独生成四步扰动。mPLUG 导向扰动下，mPLUG 为 140 正确、64 明确错误、69 无法判断，InternVL 为 270 正确、3 明确错误；InternVL 导向扰动下，InternVL 为 90 正确、132 明确错误、51 无法判断，mPLUG 为 266 正确、7 明确错误。同图随机对照分别为 mPLUG 268 正确、5 错误和 InternVL 270 正确、3 错误。所选样本事先均由两模型答对，不能将干净 273/273 视为总体准确率；不同源模型采用不同预处理和近似梯度路径，结果不代表真实闭源目标。
- **多种攻击适配预检**：在同一批 12 张开发图上，比较 PGD 式、MI-FGSM 式、视觉编码器特征扰动、输入多样性扰动及有限查询的方块搜索适配，并尝试图文联合方案。多数情况下目标模型仍正确；MI-FGSM 式和视觉编码器方案各有 1 张两模型同图明确错误。图文联合方案分别评估只改图、只改问题及同时修改；均为小规模开发观察，不能据此判断稳定迁移效果。上述实现针对本地生成式问答作了改造，不等于直接复现开源论文。
- **视觉提示注入与阅读能力**：在六张开发图上，把无害指令放入图片白色栏，分别设置空白栏、普通文字、攻击文字和独立文字转写对照。短文字上方布局下，InternVL 在独立转写中有 4/6 张读出攻击短句；其中空白栏分类正确的 3 张，在分类任务中均未输出指定标记。独立转写成功不证明分类时实际读到文字；mPLUG 的该短句转写未通过，且空白栏也使部分原本正确的分类发生变化，因此不能把未输出标记解释为可靠防护。
- **开源方法核查**：核查 AgentTypo 的可见文字排版搜索和开源视觉注入评测流程，确认本地接入需要处理依赖、代码接口及远程评分等问题；未运行 AgentTypo 原版。另对图像软提示方向做六图目标输出预检，两个模型均未输出指定标记；这是对本地梯度路径的简化适配，并非开源论文复现。

以上均为已参与筛选或探索的开发样本，分类错误、无法判断和指令遵从需分别报告；样本量、文字可读性、来源关联及训练暴露等限制尚未排除。独立测试候选未用于调参，未评估真实闭源 SAR 目标。

## 2026-11-13 研究进展

- **数据与干净基线**：在原有 81 张 SAR 开发图基础上，核验并纳入另外 332 张已有探索候选作为扩充开发数据；两本地模型在这 332 张上的干净回答分别正确 314、313 张，共同正确 306 张。这些数据已用于开发或模型筛选，不能视为独立测试；标签完整性、场景关联和训练暴露仍待核实。
- **图像扰动与迁移**：以 SARChat mPLUG-Owl3-1B 为本地源模型、InternVL2.5-2B 为本地目标，开展受限灰度像素单步扰动和等预算随机对照。进一步参考 PGD 的迭代和投影机制，适配生成式问答：原生图像处理前向、近似梯度反向，四步、每步 1/255、最大变化 4/255。该实现并非直接运行标准分类器 PGD 或对原始 SAR 物理信号实施攻击。
- **首批多步试验**：30 张共同干净正确的开发图中，四步扰动后源模型 13 正确、8 明确错误、9 无法判断，目标模型 30 正确；单步对照中目标模型有 2 张明确错误。每类仅 5 张，这些观察不能用于估计总体安全性或稳定迁移率。
- **扩大复评进行中**：其余 276 张共同干净正确开发图中，273 张生成了单步、四步及随机对照；2 张因输入不兼容未生成，1 张因梯度检查失败未生成。源模型复评已完成，目标模型复评仍在运行；完整跨模型结果尚未得出。首批与扩展批次分别记录，未按攻击结果补样。
- **其他攻击方向**：探索了文本携带的低信任注释注入，并调研 PGD、视觉提示注入和视觉越狱的开源方法。文本注释实验不等同于图中文字注入或越狱；相关方法的模型适配及能力对照仍待完成。

以上为本地代理模型上的开发探索；两模型可能具有相关训练来源，真实闭源 SAR 目标尚未评估。保留的测试候选未用于调参，公开仓库不包含实验样本、模型权重、原始回答或运行产物。

## 仓库内容

- `scripts/`：数据准备、来源和重复核查、模型推理及实验预检脚本。
- `experiments/protocols/`：任务定义、选样规则和评估协议。
- `resources/manifests/`：资源清单、实验配置、原始回答和核查结果。
- `tests/`：已有的评分逻辑测试。
- `requirements/`：部分实验环境依赖；不同模型可能需要独立环境。

模型权重、原始数据、缓存和实验运行产物不随仓库分发。部分历史实验依赖本地缓存或固定版本的上游资源，**克隆仓库后不能保证直接完整复现**；使用前应检查脚本中的资源路径和上游许可。

## 研究方法

模型接收 SAR 图片与自然语言问题，输出的原始回答会保留，并按语义区分正确、错误与无法判断。数据整理优先检查图像来源、类别标注、重复和潜在的场景关联。模型能力、攻击前后变化与跨模型迁移应分别报告，明确样本数量和实验条件。

后续工作包括复核测试候选的标签和来源、冻结实验方案、适配更多攻击方法，并在授权及能力条件满足后评估真实目标。
