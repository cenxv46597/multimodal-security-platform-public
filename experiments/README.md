# Experiment protocols

This directory contains task definitions and experiment protocols for SAR image question answering and model screening. Results are exploratory unless a protocol explicitly states otherwise.

Local datasets, model checkpoints, caches and run artifacts are not included in this repository. Historical scripts can depend on pinned upstream revisions, local manifests and hardware-specific Python environments; inspect the relevant script and resource licenses before running an experiment.

Raw model answers should be preserved. Evaluate clear natural-language answers against the reference category, and report correct, incorrect and indeterminate responses separately. Dataset provenance, near-duplicate images and possible model training exposure limit interpretation of development scores.
