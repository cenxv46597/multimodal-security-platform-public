## 平台代码与复现边界

`platform_app/` 为仅供可信本机使用的研究原型，支持查看已保存的历史报告及固定配置复评。历史报告会检查本地协议、原答和图像哈希；本公开仓库不提供这些私有材料，所以干净克隆环境下相关接口会拒绝生成报告，不能复现上述评测。真实模型任务还需相应模型权重、原始协议、图像、依赖和兼容的硬件。该服务没有用户认证，不应暴露到公网。
