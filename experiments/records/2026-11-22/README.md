# 2026-11-22：SAR 消融与候选重叠筛查

## 图片、问题和对照

模型看到同一张 SAR 图片，用户要求从船、飞机、汽车、储油罐、桥梁和港口六类中选出目标类别，并用自然句回答。每张图的干净图检查基本识别；已有随机扰动对照检查等最大像素变化下的回答；完整方法和移除视觉余弦损失的版本检查该损失在同图配对中的影响。两模型均使用干净图先前回答正确的六张已有开发图。先完成船图试验，再在观察试验后确定按原有顺序执行其余五图，因此不能声称六图方案事先整体冻结。

## 结果和边界

两种方法的源模型各命中预设错误类别 6/6；目标模型各命中 1/6，另 5/6 回答正确。两个模型各六条完整方法与消融方法的分类答案逐项相同；唯一目标命中为飞机答成船，同图原图和已有随机对照均答成飞机。逐图脱敏原答和条件见 [results.json](results.json)，执行规则见 [protocol.json](protocol.json)。这不能证明视觉余弦损失普遍无作用，也不能证明稳定迁移：样本少、已使用且基于两模型干净正确筛选，场景独立性、标签和训练暴露仍待核验。

飞机图源端生成曾分别因缺少 torchvision 和 UnboundLocalError 失败；用户明确授权修正后再次执行。两次失败均保存在本地，不计作成功调用。其余五图生成 5/5，两个模型评测共 10/10 完成。

## 候选图片的局部重叠筛查

新增[成对筛查工具](../../../scripts/sar_overlap_screen_20261122.py)和合成数据测试：对同尺寸方形图尝试旋转、镜像和位移，再用重叠区域相关性提出人工复核候选。工具阈值借助一对已知疑似重叠图开发；该对不能充当独立召回率验证。未扫描全部候选图对，未检出也不代表场景独立；跨尺寸、非方形、尺度变化等不在当前覆盖范围。243 张候选仍未审核冻结，不用于调参或根据模型表现筛选；复核界面的未审核状态和另存的少量非专家试评记录并存。

尺寸清点显示候选间 29,403 对中 15,049 对符合当前尺寸条件；候选与 413 个开发输入之间 100,359 对中 50,771 对符合。此为尺寸覆盖统计，并非筛查结果。图片、标识、哈希、权重和运行产物保留本地。

## 离线验证

安装 Python、NumPy 和 Pillow 后，在仓库根目录执行 `python -m unittest discover -s tests -v`；本次公开前运行 30 项，全部通过，其中 5 项针对合成图片筛查。工具输出输入文件的 SHA-256，使用真实图片时应按私人材料处理输出。工具仅经本机离线验证，完整候选扫描与其他环境尚未验证。
